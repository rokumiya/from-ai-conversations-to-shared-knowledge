# AIとの会話に、**「この部分を共有する」**という操作があったらどうだろう。

**利用者は、自分の発見を誰かに渡せる。誰かの発見も受け取れる。**  
日々の工夫や経験、思いつきを、別の投稿に書き直す手間なく共有できる。自分が困ったときには、他の人が共有した発見に出会える。

**AI提供者は、新しい情報が継続的に集まる入口を持てる。**  
利用者が試したことや、最近気づいた変化が、次の対話で参照できる情報源になる。

## 一言の発見でも共有できる

共有するものは、大げさな知識でなくてよい。

- 半熟卵のトッピングに柚子胡椒を少し乗せるとおいしかった。
- ホットケーキメーカーには、意外とこんな使い道があった。
- この作業は、毎回ここで同じ無駄が発生している気がする。
- この道具は、ここだけ変えればもっと使いやすくなるのではないか。
- 試した方法はうまくいかなかったが、この条件だけは関係していそうだ。
- まだうまく説明できないが、こういう仕組みが必要なのではないか。

ここでいう共有知は、正しさが確認された知識だけを指さない。一行の生活上の工夫、個人的な経験、疑問、失敗、未検証の思いつきも含む。

今回の提案のように、短いSNS投稿にするには長すぎ、記事や企画書にするにはまだ固まっていない考えでもよい。

重要なのは、それが立派な成果物であることではない。

**本人が「これは共有したい」と思ったこと**である。

立派な記事に仕上げたり、細かな項目を埋めたりせず、雑に共有できることが大切だ。

## AIとの会話では、すでに多くのことが言葉になっている

人はAIとの会話で、質問に答えてもらうだけではない。

- 自分の状況を説明する。
- 昔の経験を思い出す。
- 何が不便なのかを言葉にする。
- 思いつきを試しに話してみる。
- AIの返答に反論する。
- 考えを少しずつ整理する。
- 試した結果を報告する。
- 最初にはなかった考えへたどり着く。

この過程では、これまでなら頭の中だけで終わっていたことが、すでに文章になっている。

しかし、会話が終わると、その大部分は社会的には消える。

会話履歴が個人のアカウントに残っていたとしても、他の人が検索し、引用し、関連する考えと結び付けられる共有知としては存在しない。

Xなどへ投稿すれば、短い一言でも公開されたURLを持ち、誰かが見つける可能性が生まれる。ブログに書けば、より長い考えも残せる。

だが、AIとの会話からあらためて投稿や記事を作るには、もう一度次のことをしなければならない。

- どこを取り出すか決める。
- 前後を知らない人にも分かるように書き直す。
- 投稿先を選ぶ。
- 長さや形式を合わせる。
- 個人的な文脈を削る。
- 公開してよい内容か確認する。

短い一言ならXへ書けばよいかもしれない。それでも実際には書かれないことが多い。

まして、まだ名前も付いていない複雑な考えは、短い投稿には収まらず、記事にするほど完成してもいない。その中間にあるものほど、出力先を持たないまま消えやすい。

この最後の壁を、AI自身が低くできるはずである。

## 共有すると、別の人の対話へ届く

たとえば、先ほどの半熟卵の話なら、会話の中で「この部分を共有する」を選ぶ。必要ならAIが会話の外でも読める文章に整え、本人が文章を確認して共有する。

後日、別の利用者が卵の食べ方を相談したとき、AIが「こんな食べ方を共有した人がいます」と、元の投稿を示しながら紹介する。

元の会話は非公開のまま、本人が選び、確認した文章だけを共有する。

## 既存の機能をつなぐところから始められる

AIが文章を整える、投稿を保存して検索する、見つけた情報を対話で紹介する。必要なのは、これらを次の流れにつなぐことだ。

**会話の一部を選ぶ → 本人が確認して共有する → 別の人の対話で見つかる**

新しい基盤技術を待たずに、既存技術の組み合わせから試せる。共有した文章を検索して紹介する仕組みなので、モデルの再学習を待つ必要もない。

まずは、共有した文章を同じサービスの利用者全員が閲覧できる形でよい。一社のサービス内だけでも、ある人の発見を別の人へ渡す目的は達成できる。公共Webへの公開や他社サービスとの連携を、実現の条件にする必要はない。

## なぜ、この入口がほしいのか

AIとの私的な対話だけで問題解決が完結すると、以前なら掲示板やブログなどに書かれていた経験や発見が、他の人へ届かなくなるのではないか。AIが既存の共有知を利用する一方で、新しい情報が共有知へ加わる機会が減っていくことが気になっている。

人は、発見したことを誰かに話したくなる。すでにAIとの会話で言葉になっているのなら、その場から簡単に共有できるとよい。

この提言自体も、AIとの会話から生まれた。「この部分を共有したい」と思ったものの一例である。
